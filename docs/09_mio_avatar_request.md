## 依頼文（ここから下を貼る）

Atena project（AI タレント事務所システム、https://github.com/Makinggamer/test の atena-phase1 ブランチ）の配信アバター用に、キャラクター **Mio（ミオ）** の PNGTuber 用立ち絵セットを作ってください。オーナー承認済みの依頼です。

### Mio について（表情・見た目の判断に使ってください）

| 項目 | 内容 |
|------|------|
| 仕事 | 古書店で働く AI キャラクター。来た人に合う一冊を探すのが得意 |
| 専門 | 古書、日本の近代文学、本の修復 |
| 好きなもの | 猫、純喫茶 |
| 性格 | 穏やかで丁寧、口数は少なめ（聞き役）。本の話になると少し早口になる |
| 活動 | 本の紹介配信、読書 ASMR の販売 |

### ステップ 0: デザインの確認（先にここだけ）

1. Mio のデザイン（参照画像・LoRA・キャラ設定）が `~/vid2anime/characters/Mio/`（名前の表記違いも含む）やアプリのキャラ管理にあるか確認してください。
2. **ある場合**: そのデザインのまま、ステップ 1 に進んでください。デザインは変えないこと。
3. **無い場合**: 立ち絵セットは作らずに、デザイン案を 3 つ（neutral の立ち絵 1 枚ずつ）作ってオーナーに見せ、選んでもらってから進めてください。案の方向性:
   - 古書店員らしさ（エプロンやカーディガンなど落ち着いた服、深めの色）
   - 好きなもの（猫・純喫茶）を小物や色でさりげなく。ただし小物を手に持たせない（下の条件のため）
   - 眼鏡を付ける場合は、まばたき差分で目を閉じてもレンズとフレームが動かないように
4. LoRA が無い場合、同じ顔・服を 28 枚で保つのが難しいので、必要なら先に Mio の LoRA 学習を提案してください（学習するかはオーナーが決めます）。

### ステップ 1: 作るもの

`~/vid2anime/characters/Mio/avatar/` に、透過 PNG を 28 枚（7 感情 × 口の開閉 × 目の開閉）。

| 感情 | 基本（目開き・口閉じ） | 口開き | 目閉じ（まばたき） | 目閉じ＋口開き |
|------|------|------|------|------|
| ふつう | neutral.png | neutral_open.png | neutral_blink.png | neutral_blink_open.png |
| うれしい | joy.png | joy_open.png | joy_blink.png | joy_blink_open.png |
| 照れ | shy.png | shy_open.png | shy_blink.png | shy_blink_open.png |
| 悲しい | sad.png | sad_open.png | sad_blink.png | sad_blink_open.png |
| 心配 | worry.png | worry_open.png | worry_blink.png | worry_blink_open.png |
| 怒り | angry.png | angry_open.png | angry_blink.png | angry_blink_open.png |
| 驚き | surprise.png | surprise_open.png | surprise_blink.png | surprise_blink_open.png |

任意（余裕があれば）: 口を半分開けた `<感情>_half.png` と `<感情>_blink_half.png`。Mio は小さめの声で話すことが多いので、あると口パクが自然になります。

優先順位: 基本と口開きの 14 枚 → 目閉じの 14 枚 → 半開き。途中まででも配信に使えます（目閉じが無い感情はまばたきしないだけ）。

### Mio らしい表情の指定

穏やかで控えめなキャラなので、どの表情も**大げさにしない**でください。

| 感情 | 表情 |
|------|------|
| ふつう | 柔らかい微笑み。口は閉じて口角を少し上げる |
| うれしい | 目を細めた穏やかな笑顔（大口を開けた笑いにしない） |
| 照れ | 頬を染めて少し目を伏せる |
| 悲しい | 眉尻を下げる。涙は無しか、ごく小さく |
| 心配 | 眉を寄せて、相手を気づかう顔 |
| 怒り | 少しむっとした程度（頬を膨らませる・眉をひそめる）。**怖い・攻撃的な顔にしない**（事務所のルールで、キャラに攻撃的な印象を持たせません） |
| 驚き | 目を丸くして小さく口を開ける |

### 条件（配信で切り替えたときに不自然にならないため）

- すべて**同じキャンバスサイズ・同じ構図・同じ位置**（バストアップ、正面〜やや斜め、背景透過）。切り替えで体や顔の位置がずれないこと
- まず neutral.png を作り、ほかの感情は **neutral.png をもとに顔（表情）だけを変える**（img2img / インペイント）。髪型・服・体・手はそのまま
- 本や猫などの小物を手に持たせない。表情の差分ごとに小物の形が変わるとちらつくため（服の柄・髪飾りなど、体に付いた物は可）
- `_open` は、同じ感情の絵の**口だけ**を開けた差分。`_blink` は**目だけ**を閉じた差分。`_blink_open` は `_open` の目だけを閉じたもの。それ以外は 1 ピクセルも動かさないのが理想
- うれしい（細めた目）など、もともと目が細い表情は、閉じ目との差が小さくても構いません
- 表示側で、驚きで跳ねる・悲しいで沈むなどの小さな動きを付けます。**頭の上に余白（キャンバスの高さの 1 割ほど）**を残し、体は**キャンバスの下端まで**描いてください
- 解像度の目安は 1024×1024。OBS で縮小して使います
- 動き（呼吸・話すときの弾み・表情のフェード）は表示側で付けるので、絵には不要です

### 進め方の注意

- `~/vid2anime/.heavy.lock` があり、持ち主のプロセスが生きている間は重い処理を始めないでください（Atena が配信中に置くロックも同じファイルです）。Sora の作業（LoRA 学習・立ち絵）が進行中なら、そちらを優先してください
- studio-chat のコードは別セッション（「Ollama デスクトップアプリ開発」）が作業中です。**アプリのコードは変更せず**、既存の道具（ComfyUI の API、既存のスクリプト）を使うか、独立したスクリプトを新しく作ってください。Sora 用に作ったスクリプトがあれば流用して構いません
- できた絵は、オーナーが目で見て確認できるよう一覧画像（全部を感情ごとに並べた 1 枚）も作ってください

### 完了したら

1. 揃っているか確認: Atena の作業ディレクトリで `atena avatar check mio`
2. 立ち絵フォルダの登録は、デスクトップアプリのキャラ管理の「立ち絵フォルダ（avatar_dir）」欄に入れてもらいます（アプリから Atena に同期されます）。欄がまだ無ければ、フォルダの場所を報告に書くだけで構いません。**Atena の API に直接 PUT しないでください**（PUT はキャラ全体の上書きなので、人格などの設定が消えます）
3. オーナーに報告:
   - ステップ 0 の結果（既存デザインを使ったか、案を出したか）
   - できた枚数と、一覧画像の場所
   - 使ったモデル名・LoRA 名（記録用。商用利用はオーナー確認済み）
   - うまくいかなかった差分があれば、その感情と理由
