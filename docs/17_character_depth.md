# キャラの個性・人間らしさを出すには

初回のラウンジで「AI 感が強い」「Mio と Sora の違いがほぼ無い」という指摘を受けての整理と対応です。

## なぜ AI っぽく、似てしまうのか

| 原因 | 説明 |
|------|------|
| 人格の情報が少ない | 人格が 1〜2 文だけだと、小さなモデル（7B）は「感じのいいアシスタント」の口調に戻ってしまう。口調の手がかり（一人称・語尾・例文）が無いと、どのキャラも同じ優等生になる |
| 指示が「いい人」に寄っている | 事務所のルール（攻撃しない・前向きに）だけが強く、「好き嫌い」「こだわり」「反対意見」を言う余地がなかった |
| 考えずに即答している | いきなり発言させると、相手の言葉をなぞる・まとめる・肯定する、という AI の癖がそのまま出る |
| 決まり文句 | 「なるほど」「確かに」「素晴らしい」などで始めるのが典型的な AI 口調 |
| 毎回同じ状態 | 気分や体調の揺らぎがないので、毎回同じテンションになる |
| 生成の設定が全員同じ | 同じモデル・同じ揺らぎ（temperature）なので、言葉選びが似る |

## 実施したこと（Atena 側・反映済み）

1. **キャラ設計書**（`atena character deepen`）
   人格の文章から、会話で個性が出る具体的な設定を下書きして保存します。
   一人称 / 語尾・口調 / 口癖 / 話し方の例（5つ）/ 大事にしていること / 苦手なもの / 考え方の癖 / ほかのキャラの呼び方と関係 / 生成の揺らぎ。
   - ほかのキャラと口調・考え方がかぶらないように作ります
   - **人格の文章は変えません**（Atena 側の追加項目だけ。アプリからの同期でも消えません）
   - 作った内容は Discord の #運営報告 に出します。気に入らなければ `--reset` で消せます
   - 自動運転では、設計書の無いキャラに毎朝自動で作ります
2. **本音 → 発言の 2 段階**
   まず心の中で「自分ならどう感じるか・賛成か反対か・何を思い出すか」を考えさせ、そこから一言を言わせます（本音は公開しません）。
3. **人間らしい雑談のルール**
   相手の言葉をなぞらない / 何でも肯定しない（やんわり違う意見を言ってよい）/ 一般論でなく自分の具体的な話 / 話し言葉。
4. **決まり文句の除去**
   「なるほど」「確かに」「素晴らしい」などで始めたら 1 回言い直させ、それでもなら決まり文句を削ります。
5. **その回の気分**
   ふつう / 少し眠い / 機嫌がいい / 考えごと / わくわく / 少し疲れ を回ごとに抽選（ふつうが多め）。
6. **キャラごとの生成の揺らぎ**
   落ち着いたキャラは低め、奔放なキャラは高めの temperature。同じ言い回しの繰り返しを抑える設定も追加。
7. **振り返りの観点を追加**
   マネージャーの振り返りで「キャラ同士の違いが出ているか」「AI っぽい言い回しが出ていないか」を見て、次回の心がけに反映します。

## オーナーが決めると、さらに良くなること（任意）

| 案 | 効果 | 必要なこと |
|----|------|-----------|
| A. 人格の文章を厚くする | 一番効く。生い立ち・口癖・好き嫌い・人との距離感が書かれているほど、設計書も会話も個性的になる | アプリのキャラ管理で人格を書き足す（設計書の内容を参考に、気に入った部分を人格に取り込むのも可） |
| B. キャラ設計書を手で直す | 「Mio はもっと毒舌に」など細かい好みを反映 | このセッションに「Mio の口癖を〇〇に」と伝える（こちらで反映） |
| C. 会話用のモデルを変える | qwen2.5:7b は真面目な口調に寄りがち。日本語の会話・ロールプレイが得意なモデルにすると口調の幅が広がる | 候補を試して比べる（Windows PC の Ollama で試すと Mac の負担なし）。キャラごとに別モデルも可 |
| D. 他キャラとの関係を決める | 「ミオはソラを妹のように見ている」など。掛け合いに方向性が出る | このセッションに伝える（設計書の relations に反映） |

## Mac での反映

```bash
cd ~/atena && git pull origin atena-phase1 && source .venv/bin/activate
atena character deepen          # Sora と Mio の設計書を作る（結果は画面と #運営報告 に）
atena lounge sora mio --topic 猫 --turns 8
```

自動運転は動いたままで構いません（次のラウンジから新しい話し方になります。自動運転のプロセスはコード更新後に再起動が必要: `launchctl unload -w ~/Library/LaunchAgents/com.atena.autopilot.plist && launchctl load -w ~/Library/LaunchAgents/com.atena.autopilot.plist`）。
