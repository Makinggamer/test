## 1. 作成済み（Atena 本体）

| 分野 | できること | 主なコマンド |
|------|-----------|-------------|
| 設計書 | 役職17種、企画書、要件定義、セットアップ手順、既存システムの採用判断 | `docs/01`〜`06` |
| キャラ管理 | キャラ定義、Ollama モデル・Open WebUI からの取り込み、アプリからの同期 | `atena character` |
| ガーディアン | 差別・暴力、オーナー個人情報、配信環境・内部情報、設定の漏洩、仲間への攻撃を検査し、止める・伏せ字にする・言い直させる | `atena guardian` |
| コメントモデレーター | 荒らし・誘導（設定を聞き出す等）・視聴者の個人情報を、キャラに届く前に除去 | — |
| 記憶マネージャー | キャラごとの記憶、容量超過時の要約・忘却、視聴者ごとの覚え書き | `atena memory` |
| 専門知識・学習係 | 好きなもの・仕事について Wikipedia・一般 Web 検索・登録サイト・コメントから学習。情報源で優先順位（オーナー＞参考資料＞Web＞コメント）、食い違いは Web 優先、容量はマネージャーが整理 | `atena learn` / `atena expertise` |
| 場繋ぎ | コメントが 40 秒途切れたら、好きなもの・専門の話をして問いかける | 配信中に自動 |
| マネージャー | 日次サイクル（企画の提出・審査・ネタ被り調整・翌日の枠の仮押さえ・学習・ラウンジ）、承認、状況レポート | `atena daily` / `atena report` |
| リソースモニター | M3 Mac の CPU・メモリ・GPU・スワップ・Ollama 使用量を監視。高負荷なら配信の開始を止め、配信中は早めに締める | `atena monitor` |
| GPU の取り合い防止 | アプリの `~/vid2anime/.heavy.lock` を尊重し、配信中は Atena も同じロックを置く | 自動 |
| 収益・ランキング | 収益台帳、直近 30 日ランキング、スパチャの自動記録（円換算） | `atena revenue` |
| ラウンジ | 毎日自動開催。性格（口数）で発言量が変わり、黙っているキャラには話を振る。情報交換回と好きなもの雑談回。規制・ノウハウ化・切り抜き候補 | `atena lounge` / `lounge-log` / `lounge-show` / `highlights` |
| YouTube 配信 | ライブチャット取得（API キー / OAuth）、割り当て（クォータ）の自動配分、スパチャ記録 | `atena youtube` |
| 声 | Irodori-TTS-Server で読み上げ（感情ごとの喋り方）。失敗時は声を変えず「ボイストラブル中」の注意書き＋字幕のみ | `atena voice` |
| 字幕・OBS | 字幕・読み上げ中コメント・注意書きをテキストファイルで出力、配信の字幕を SRT 保存 | 自動 |
| アバター | 内蔵 PNGTuber（OBS ブラウザソース、7 感情×口パク）、VTube Studio 連携、仮の立ち絵の自動生成 | `atena avatar` |
| アプリ連携 API | キャラ同期、ガーディアン検査、返答、予定・ランキング・承認・PC 状態・知識・ラウンジ履歴 | `atena serve`（127.0.0.1:8770） |
| 監査ログ | すべての判断・違反・承認を改ざん検知つきで記録 | `atena audit-verify` |
